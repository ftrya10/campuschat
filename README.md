# Campus Chat

Campus Chat merupakan aplikasi chat berbasis web yang dibuat menggunakan Laravel 12 dan React. Aplikasi ini digunakan untuk komunikasi antar pengguna secara realtime.

## Fitur
- Login dan register
- Chat realtime
- Tampilan responsive
- Aktivitas user

## Teknologi
- Laravel 12
- React JS
- Vite
- MySQL

## Cara Menjalankan Project

1. Clone repository
```bash
git clone https://github.com/ftrya10/campuschat.git
```

2. Masuk ke folder project
```bash
cd campuschat
```

3. Jalankan project
```bash
php artisan serve
npm run dev
```
