# Campus Chat

Campus Chat merupakan aplikasi chat sederhana berbasis web yang dibuat menggunakan Laravel 12 dan React. Aplikasi ini dirancang untuk membantu komunikasi antar pengguna dalam lingkungan kampus secara realtime.

## Fitur
- Login dan register
- Chat realtime
- Tampilan responsive
- Status aktivitas pengguna
- Sistem autentikasi user

## Teknologi
- Laravel 12
- React JS
- Vite
- MySQL
- Pusher
